# 起動手順・利用者向け操作説明書

## 1. 起動手順（Windows PC / Mac 共通・管理者権限不要）

本アプリはサーバーサイドの追加ライブラリ（`pip install` 等）や管理者権限を一切必要としません。以下の **2通りの方法** のどちらでも起動できます。

### 方法A：HTMLファイルをブラウザで直接開く（最も簡単）
1. フォルダ内の **`index.html`** をダブルクリックし、Edge または Chrome で開きます。
2. 最初から **105件のデモ蔵書データ（ご提供いただいた4冊の奥付書籍データを含む）** が読み込まれた状態で即座に動作します。
3. 自動単体テストをブラウザ画面で確認したい場合は **`test_runner.html`** を開いてください。

### 方法B：Pythonでローカルサーバーを起動する（カメラAPI検証時などに推奨）
ブラウザのセキュリティ仕様上、カメラ（`getUserMedia`）は `http://localhost` または `https://` 上で動作するため、PCカメラを試す場合は以下を実行してください。
* **Windowsの場合**: **`start_windows.bat`** をダブルクリックする（またはコマンドプロンプトで `python start_server.py` を実行）。
* **ブラウザで開くURL**: `http://localhost:8080/index.html`

## 2. 利用者向け操作説明：iPhone現場モード（現物の読取・照合・選択）

画面上部の切替タブで **「📱 iPhone現場モード（読取・選択）」** を選びます。片手（親指）でタップしやすい縦1列レイアウトになっています。

### ステップ1：照合対象リストの確認・読込
* 初期状態では「デモデータ105件」がセットされています。
* PC側で作成した最新の「スマホ用照合データ（JSONまたはCSV）」を使う場合は、**「📥 照合ファイル読込 (JSON/CSV)」** ボタンからファイルを選択します。

### ステップ2：移動先の保管場所を先に指定する（連続登録対応）
複数冊を同じ書架または同じ外部倉庫箱へ続けて登録できるよう、**先に移動先を固定セット**します。
1. **🏢 本部内の書架・保管場所へ移す場合**
   * 「🏢 本部内の書架・保管場所」ボタンを選び、移動先の書架名（例：`本部 4F イノベーション書架B-1`）を入力するか、定型書架プルダウンから選択します。
2. **📦 外部倉庫（日高倉庫）の文書箱へ箱詰めする場合**
   * 「📦 外部倉庫（日高）箱詰め」ボタンを選びます。
   * 「部・Gコード（例：`1101`）」と「年度2桁（例：`26`）」を入力して **「次番号を提示」** を押すと、未使用の次番号（例：`1101-26-0003BOK`）が自動計算されて入力されます。
   * 形式（`部室G-年度2桁-通し番号4桁BOK`）と既存箱との重複がリアルタイムでチェックされます（※「仮」などの仮箱番号はエラーとなり登録できません）。

### ステップ3：書籍の奥付を読み取る（3つの手段をいつでも切替可能）
* **📷 実機カメラ読取（連続スキャン）**
  * **「▶️ カメラ開始（連続読取）」** を押すとカメラが起動し、シャッターボタンを押さなくても約2秒間隔で自動フレーム解析を行います。
  * カメラが起動できない環境や照明反射時は、すぐ下の **「📸 奥付写真を選択してブラウザ内OCR実行」** または **「iPhone標準キーボードの『テキスト認識表示（カメラアイコン）』を使った直接入力」** が使えます。
* **🧪 模擬OCR検証（実機カメラなしでのテスト用）**
  * 添付いただいた4冊（『AIを使って考えるための全技術』『そして僕たちは、組織を進化させていく』『［新版］概説 交通事故賠償法』『人事制度の基本』）や、OCRかすれ・ISBNなし図書の模擬OCRテキストをプルダウンから選んで照合ロジックをテストできます。
* **🔍 手動キーワード検索**
  * ISBNがない社内規程集や、OCRでうまく読めない古書などは、ワンタップで手動検索タブに切り替え、図書登録番号・書名・著者・ISBNの一部で即座に検索できます。

### ステップ4：候補から対象の図書を人が確認して選択する
* **重要ルール**: 同じISBNの複本（例：`BK-00001` 第1刷・デジタル推進室 と `BK-00002` 第3刷・経営企画部）がある場合、アプリは絶対に1冊へ自動確定しません。
* 候補カードに表示される **「図書登録番号」「版・巻号」「所管部署」「現在の保管場所」** を現物と照合し、**「👆 この図書を選択し移動先へ登録」** ボタンを押します。
* **二重追加防止**: すでに選択済みの図書登録番号はボタンが「選択済みです」と無効化され、連続読取で同じ本が何度映っても重複追加されません。

### ステップ5：中断・再開と変更データの出力（CSV / QRコード）
* 選択したリストは1冊ごとにブラウザ内（`localStorage`）へ自動保存されるため、途中でブラウザを閉じても再開できます。
* 選択が終わったら、以下のいずれかでPCへデータを渡します。
  1. **「📤 変更用CSVを出力」**: BOM付きUTF-8のCSVファイルを出力し、メール添付・Teams・共有フォルダ等でPCへ渡します。
  2. **「🔳 PC受け渡し用QRコード表示」**: 画面上にQRコードを生成・表示します（冊数が多い場合は自動で複数ページに分割され、「◀ 前へ / 次へ ▶」で切り替えられます）。

## 3. 利用者向け操作説明：PC台帳管理モード（比較・台帳更新・別紙2-3出力）

画面上部の切替タブで **「💻 PC台帳管理モード（比較・出力）」** を選びます。5つのサブタブに分かれています。

1. **📚 1. 蔵書一覧・検索・スマホ用出力**
   * 全蔵書の横断検索、所管部署・保管区分（本部内／外部倉庫）・ISBN有無での絞り込み、ISBNチェックディジット異常の確認ができます。
   * **「📱 スマホ用照合データ出力 (JSON)」** でiPhoneへ渡す照合ファイルを出力できます。
2. **📥 2. 台帳CSV取込・列マッピング・検証**
   * 既存の蔵書台帳CSV（UTF-8 または Shift_JIS）を選択すると、**元CSVの列名と標準11項目を対応付けるマッピング画面**が表示されます。
   * 取込時に「図書登録番号の重複」「必須項目（登録番号・書名）の欠落」「ISBN形式異常」を自動検査します。
3. **🔍 3. スマホ変更データの取込・変更前後比較・更新CSV出力**
   * iPhoneで出力した「変更用CSV」または「QRコード（カメラ読取／文字列貼付）」、あるいは同一ブラウザ内の選択リストを取り込みます。
   * **「変更前の保管場所 ➔ 変更後の保管場所」「変更前の箱番号 ➔ 変更後の箱番号」** が並べて比較表示されます。
   * 更新対象にチェックを入れ、**「📤 更新済みの全件台帳CSVを別ファイル出力」** を押すと、元ファイルを上書きせず新しいCSVファイルとして出力します（Excelで `00120` 等の先頭ゼロが消えない保護オプション付き）。
4. **📦 4. 外部倉庫（日高）管理・別紙2-3出力**
   * 部・G・年度ごとの次の空き箱管理番号の算出と、箱単位で集計した **「別紙2-3 転記用データ」**（文書等種類：`文書`、保存期限：`永久 / 2999/12/31`、名称：`図書（部署名）計○冊：主な書名…` を100文字以内に自動整形）のプレビューおよびCSV出力を行います。
5. **🕒 5. 変更履歴・バックアップと復元**
   * いつ・何件の場所変更を反映したかの履歴一覧と、**「⏪ この変更前の状態に戻す」** によるワンクリック復元、および全体バックアップJSONの保存・復元が行えます。
